- `safira-btg-logo-colorido.png` — logo horizontal para fundo claro (PNG transparente)
- `safira-btg-logo-branco.png` — logo horizontal para fundo escuro (PNG transparente)
- `safira-simbolo-gema-3d.png` — símbolo em safira 3D, para capas e encerramentos
- `safira-simbolo-flat.png` — símbolo "S" chapado em azul, transparente (234×333 px, só para uso pequeno)
- `safira-favicon.png` — símbolo "S" em 64×64 px, transparente, para ícones
- `modelo-primeira-reuniao.pptx` — apresentação de primeira reunião (versão leve)
- `modelo-acompanhamento-carteira.pptx` — reunião de acompanhamento de carteira

Importante: este repositório é público. Nunca adicionar dados de clientes.
